# Android Telemetry App

Мобильное приложение для сбора данных о местоположении и качестве мобильной сети. Работает в паре с серверной частью: телефон собирает GPS-координаты и данные о базовых станциях, отправляет на сервер через ZMQ в реальном времени.

## Описание

Приложение запускает фоновый сервис, который непрерывно собирает данные о GPS и сотовых сетях (LTE, GSM, 5G NR), записывает их в JSON-файл и отправляет на C++ сервер. Работает при свёрнутом приложении и выключенном экране.

## Структура проекта

```
app/src/main/java/com/example/androidapp/
```

Основные классы:

- MainActivity - главный экран, навигация между разделами
- LocationActivity - отображение GPS-координат и данных сот в реальном времени
- LocationService - фоновый сервис сбора данных (Foreground Service + WakeLock)
- NetworkActivity - ручная отправка накопленного архива на сервер
- CalcActivity - калькулятор
- PlayerActivity - медиаплеер

## Функционал

- Получение GPS-координат через LocationManager (широта, долгота, высота, точность)
- Сбор данных сотовых сетей через TelephonyManager: LTE (PCI, EARFCN, RSRP, RSRQ, RSSI, RSSNR), GSM (ARFCN, BSIC, LAC, DBm), 5G NR (PCI, NCI, NRARFCN, ssRSRP, ssRSRQ, ssSINR)
- Запись данных в файл location_log.json
- Передача данных на сервер через ZMQ PUSH-сокет каждые 2 секунды
- Работа в фоновом режиме через Foreground Service с уведомлением

## Используемые библиотеки

- Kotlin
- ZeroMQ (jeromq) - передача данных на сервер
- org.json - формирование JSON-пакетов

## Формат данных

Каждый пакет отправляемый на сервер:

```json
{
  "location": {
    "Latitude": 55.04,
    "Longitude": 82.97,
    "Altitude": 111.5,
    "Current Time": "...",
    "Accuracy": 4.5
  },
  "telephony": [
    { "type": "LTE", "pci": 123, "rsrp": -87, "rsrq": -11 }
  ]
}
```

## Сборка

Открыть проект в Android Studio, синхронизировать Gradle, запустить на устройстве с Android 9+.

Перед запуском разрешить доступ к геолокации и состоянию телефона. В поле IP ввести адрес компьютера с запущенным сервером, телефон и компьютер должны быть в одной сети.
