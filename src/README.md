# Моделирование движения человека

В проекте реализованы две математические модели для имитации движения в двумерном пространстве (Картезианская система координат).

## 1. Random Walk Model (Модель случайного блуждания)

**Принцип работы:** На каждом шагу движение является абсолютно случайным. Направление и длина шага не зависят от предыдущих значений.

**Формулы:**
1.  Генерация случайного направления в радианах:
    `direction = random() * 2 * π`
2.  Генерация случайной длины шага (от 0 до максимальной скорости `currentSpeed`):
    `stepLength = random() * currentSpeed`
3.  Вычисление приращения координат:
    `Δx = stepLength * cos(direction)`
    `Δy = stepLength * sin(direction)`
4.  Обновление позиции:
    `x = x + Δx`
    `y = y + Δy`

## 2. Gauss-Markov Mobility Model

**Принцип работы:** Эта модель добавляет "память" в процесс движения. Текущее направление и скорость зависят от своих предыдущих значений, что делает траекторию более плавной и реалистичной по сравнению с полностью случайным блужданием.

**Формулы:**
1.  Расчет нового направления на основе предыдущего (`previousDirection`). Параметр `α` (альфа) определяет степень зависимости от предыдущего значения (0 — полная случайность, 1 — прямолинейное движение).
    `newDirection = α * previousDirection + (1 - α) * randomDeviation`
    где `randomDeviation` — случайное отклонение в диапазоне `[-π/4, π/4]`.

2.  Нормализация полученного направления в интервал `[0, 2π]`:
    `normalizedDirection = (newDirection + 2π) % 2π`

3.  Расчет длины шага. В данной реализации используется вариация вокруг значения `currentSpeed`:
    `stepLength = currentSpeed * 0.8 + random() * currentSpeed * 0.4`

4.  Обновление позиции происходит аналогично Random Walk модели:
    `Δx = stepLength * cos(normalizedDirection)`
    `Δy = stepLength * sin(normalizedDirection)`
    `x = x + Δx`
    `y = y + Δy`
